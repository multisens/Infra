# TV30 — `infra/`

Infraestrutura do testbed TV30: a borda (`edgegateway`), o broker MQTT (`mqtt-broker`) e o Redis (`redis`). Este repositório é submódulo do [TV30](https://github.com/multisens/TV30), e o `docker-compose.yml` daqui só sobe incluído pelo compose da raiz do TV30.

A documentação está no [site de documentação](https://multisens.com.br/TV30/) do TV30: a arquitetura e os containers em [arquitetura](https://multisens.com.br/TV30/arquitetura/), a borda em [borda e credenciais](https://multisens.com.br/TV30/borda-credenciais/), o broker em [Mensageria (MQTT)](https://multisens.com.br/TV30/mensageria/) e o Redis em [modelo de dados Redis](https://multisens.com.br/TV30/modelo-redis/).
