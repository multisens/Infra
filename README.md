# TV30 — `infra/`

Infraestrutura do testbed TV30: a borda (`edgegateway`), o broker MQTT (`mqtt-broker`) e o Redis (`redis`). Este repositório é submódulo do [TV30](https://github.com/multisens/TV30), e o `docker-compose.yml` daqui só sobe incluído pelo compose da raiz do TV30.

A documentação está em [`docs/`](https://github.com/multisens/TV30/blob/main/docs/index.md) do TV30: a arquitetura e os containers em [arquitetura](https://github.com/multisens/TV30/blob/main/docs/arquitetura.md), a borda em [borda e credenciais](https://github.com/multisens/TV30/blob/main/docs/borda-credenciais.md), o broker em [broker MQTT](https://github.com/multisens/TV30/blob/main/docs/broker-mqtt.md) e o Redis em [modelo de dados Redis](https://github.com/multisens/TV30/blob/main/docs/modelo-redis.md).
