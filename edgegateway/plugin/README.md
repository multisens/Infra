# Plugin `tv30-auth`

O plugin da borda, que decide a credencial e a versão de cada requisição e responde a C.6.8, a C.6.7.8 e a C.6.7.9, está descrito em [borda e credenciais](https://multisens.com.br/TV30/borda-credenciais/) do TV30; os testes, em [como testar](https://multisens.com.br/TV30/como-testar/).
